# Agent Steroids starter corpus
#
# Around 500 widely used, actively maintained open source repositories,
# grouped by what they are good for. Every entry was verified against the
# GitHub API when this list was built: not archived, not a fork, committed
# to within the last year, and above a meaningful star count.
#
# Use the whole thing:
#     steroids add --from-file starter-repos.txt
#     steroids index
#
# Or take one section. Delete what you do not care about first, since every
# repo you skip is disk you do not spend and noise your agent does not have to
# search past.
#
# The whole list, measured: 480 repos, 800,000 files, 1.8 GB on disk, about
# 25 minutes to fetch and 2 minutes to index. Searches stay around a quarter
# of a second. One section is more like 100 MB and a couple of minutes.
#
# A handful of very large repos time out on a slow connection. That is fine,
# the rest still land; re-run the same command and only the missing ones are
# fetched.
